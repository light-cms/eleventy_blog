<h1>About</h1>
<p>This is a basic displayable Eleventy starter. It includes:</p>
<ul>
  <li>Home page (<code>src/index.njk</code>)</li>
  <li>Blog index (<code>src/blog.njk</code>)</li>
  <li>Post layout (<code>src/_includes/post.njk</code>)</li>
  <li>Two sample posts in <code>src/posts/</code></li>
  <li>Plain CSS in <code>src/css/style.css</code></li>
</ul>
<p>Run <code>npm run dev</code> to preview, <code>npm run build</code> to build to <code>_site/</code>.</p>
