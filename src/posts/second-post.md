description: How to add a new post.
date: 2026-02-15
tags: posts
---

To add a post, create a Markdown file in `src/posts/` with this front matter
(layout and `posts` tag are applied automatically via `src/posts/posts.json`):

```md
---
title: My Post
date: 2026-03-01
tags: posts
---
```

It will automatically appear on the home page and `/blog/`.
